# Stiiven Ottens - Staatiline veebileht

Looma muuseum (Animal Museum)

Mis see on?

Looma muuseum on lihtsalt staatiline veebileht, mis näitab paar looma pilte ning lühike kirjeldus nendest. Veebileht on koostatud inglise keeles.

Millega see on koostatud?

See on koostatud HMTL ja CSS-iga. Veebileht kasutab ainult üht CSS faili kõikide HTML leheküljede jaoks.
